# sourcegraph/deploy

> **⚠️ DEPRECATED:** This repository, and the Sourcegraph machine image (AMI)
> and k3s deployment methods it provided, were sunset in Sourcegraph 7.0.0.
> It is no longer maintained and receives no updates.

For current Sourcegraph deployment options, including Sourcegraph Cloud,
Kubernetes Helm, and Docker Compose, see the
[Deployment Overview](https://sourcegraph.com/docs/self-hosted/deploy).

If you are running an instance deployed from this repository and need help
migrating, contact [support@sourcegraph.com](mailto:support@sourcegraph.com).
